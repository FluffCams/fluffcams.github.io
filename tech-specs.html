Tech specs

How the live video works, and what you need if you run FluffCams on your own servers instead of our hosting.

How the live video works

FluffCams streams real-time WebRTC video through a media server. A model sends one stream and the server forwards it to every viewer, so the model's upload does not grow with the audience. Each viewer gets the best quality their connection can take.

Private, group and ticket shows run in their own rooms, so only the people who paid receive that video.

OBS and streaming programs

Models can stream from OBS with WHIP, which costs the server almost nothing, or with an RTMP stream key for programs that only send RTMP. Virtual cameras work like any webcam.

Our hosting

With our hosting, the website, database, media server, relay for strict networks, certificates, updates and nightly backups are all run for you.

Hosting it yourself

A Linux server with Apache, PHP 8.4 or newer and MySQL 8.0 or newer for the website, and a media server for the video. The full list of requirements is on fluffcams.com.
